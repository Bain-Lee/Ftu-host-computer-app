# 配电终端工作台界面设计

面向 FTU / DTU 调试人员，首要任务是辨认当前工程、通信状态和测点数据。采用数据密集的桌面工作台布局，避免占据表格空间的大型统计卡片与装饰动画。

## 视觉约定

| 用途 | 色值 |
| --- | --- |
| 工作区底色 | `#F1F5F8` |
| 表格与输入区 | `#FFFFFF` |
| 工具栏与正文 | `#193549` |
| 选中与主操作 | `#087D8A` |
| 边界与分隔 | `#D5E0E7` |
| 操作错误 | `#B53A3A` |

中文采用 Microsoft YaHei UI，正文 13 像素；曲线刻度采用 Consolas。表格行高 34，输入控件最低 32，按钮最低 34，标签最低 24；保留单位与变位时间。青色用于当前页签和开始运行，不用作装饰渐变。页签使用平面底色和选中下划线，采用系统窗口标题与缩放边框。

## 布局

```text
配置功能  运动功能  文件功能  升级功能  其他功能
通信配置  实时监测  遥控  参数  工程参数  历史  升级  监视  加密  开始/停止
------------------------------------------------------
当前业务页的操作栏
遥信状态及变位时间 | 遥测值及单位 | 电度值及单位
                  虚拟化表格
------------------------------------------------------
报文 / SOE / 事件页签，可关闭、独立显示和重新停靠
```

启动时自动准备并加载用户目录中的默认工程，直接显示标准模板的数据表；加载工程与连接终端是两个明确动作。全部原编译窗口均有 WPF 呈现，原来的业务术语和任务流程继续保留。

2026-10-26 针对实际显示问题调整：

- 通信配置按连接通道、规约地址、模板与加密三列组织，标签自然宽度、输入弹性伸展，分段 IP 使用独立列。
- 历史记录左侧目录、右侧内容填满；文件列表、历史列表、文件数据三种互斥内容共享一个填充区。文件信息行自然高度，表格使用剩余高度。
- 数据校验顶部放基准输入和可换行操作栏，交流、直流、相角表格互斥填满；重复打开复用当前会话数据，不再追加重复直流条目。
- 通信模块使用 IP、网关、MAC、串口、4G、主站通道、终端通道七个页签，每页操作栏和表格独立使用整个内容区。
- 实时监控三表按 36:32:32 分栏，消除空白列；名称、时间和 IP 等保留可读最小宽度。窄窗口可在表格内横向滚动，不把整页强制放入大画布。
- 数据转换输入与结果均分高度；文件传输采用本地、操作、装置三列，上下浏览区与记录区按 2:1 分配。
- 参数选择采用分组树、可选表、操作列、已选表，底部放确认与取消；加密管理按主站、运维、异常三页签组织，右侧持续显示认证数据和执行日志。
- 小型字段对话框按照原来的行和从左到右顺序自然排版；终端信息和板件类型调整默认尺寸，板件选项改为两列网格，底部操作不再越界。
- 模板配置的装置数据与内嵌参数操作区使用自动高度，标签与对应输入成组换行，表格使用剩余空间；不再使用旧 33 / 41 像素高度限制新控件。

布局回归为重点页生成 1440×900、1024×720 两种客户区视口，模板页另补 1920×1000，并检查 14 种小对话框的默认客户区尺寸，共 83 个场景。检查控件文字、窗口与操作区内部边界、表格面积和外层滚动，实际查看重点 PNG。此项属于离屏渲染验证，不代表所有显示缩放比例或设备操作验收。

## 对照需求的复核

- 保留“遥测、遥信、电度、规约、连接”等原有术语，避免把终端工具包装成通用管理后台。
- 主要视觉元素是可滚动数据表，不使用营销式大标题、仪表盘占位数据或无关统计。
- 窗口可调整大小；表格启用行与列虚拟化，数据刷新复用行对象并只通知变化的属性。
- 状态与错误均显示文字；颜色提供补充，不作为唯一提示。
- 不在初始加载时连接终端；不把代码分层、运行时版本等内部实现放进日常操作界面。
- 已对临时复制的标准模板生成离线预览，确认 400 条遥测完整进入视图；5000 条记录的测试视口只创建 19 个行控件。该结果只代表已测路径。
